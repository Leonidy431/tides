# ТЗ проекта «tides» (редакция 2026-10-03)

**Цель.** Профессиональный сервис уровня воды для BlueOS: в любой точке планеты, где у аппарата есть GPS-координаты, дать приливной ход, согласованный из трёх независимых источников, и честно сказать, где они расходятся.

## Требования

| № | Требование | Приёмка |
|---|---|---|
| 1 | Координаты берутся у BlueOS (mavlink2rest: `GLOBAL_POSITION_INT`, `GPS_RAW_INT`) или из `lat`/`lon` | тесты разбора; нулевое сообщение — не фикс, `/v1.0/here` отвечает 503 |
| 2 | Три источника рядом: теория (офлайн), глобальная модель, ближайший мареограф | `GET /v1.0/point` отдаёт статус каждого и их согласие |
| 3 | Отказ источника — статус, а не падение; кэш ответов 10 минут; таймаут 12 с | тесты с отказами |
| 4 | Согласие считается по формам рядов без среднего; теория голосует, только если одна | тесты согласия и расхождения |
| 5 | У каждого числа названы метод и лицензия; ничего не выдумывается | `/v1.0/sources`, поле `licence` в каждом ответе |
| 6 | Озёра и суша: честное «нет данных» у модели и мареографа, теория — миллиметры | тест «озеро» |
| 7 | Модуль BlueOS: метки Docker, `/register_service`, порт 9050, не от root | сборка и запуск в песочнице |
| 8 | Справочные площадки Иссык-Куля, рек и Каспия (v0.1) остаются | прежние 21 тест |

## Выбор источников (хор гуру)
Пул — 16 реальных кандидатов, выбор — тройка (560 вариантов); не 999, потому что настоящих вариантов столько нет и пул не раздувается. Оценки по шести параметрам и бонусы за разные методы и офлайн: `tools/choose_sources.py`. Готова: `equilibrium` + `openmeteo` + `ioc`. Лучшая вообще: `equilibrium` + `ioc` + `eot20` (офлайн-модель океана; нужны данные сетки) — следующий шаг.

## Не входит
Прогноз ветра и нагонов по реальной погоде; датумы мареографов и привязка к картам глубин; публикация образа в Docker Hub; проверка в шлеме и на настоящем аппарате.

## Лицензии источников
Open-Meteo — CC BY 4.0, некоммерческое бесплатно; IOC — свободно для некоммерческого с указанием источника. Перед коммерческим использованием проверить обе (юрист).

## Риски
Лимиты бесплатных API; расхождение «модель против мареографа» из-за ветра и давления (в мареографе они есть, в модели приливов их нет); IPv6 в песочнице (BlueOS в ней требует правки nginx).
